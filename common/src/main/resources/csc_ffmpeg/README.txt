FFmpeg 6.1.1 (build of the JavaCPP Presets, org.bytedeco:ffmpeg:6.1.1-1.5.10 - not the -gpl build), run as a separate program by
Concert Stage Craft to play videos on the LED walls. It is built with --enable-version3: GNU LGPL version 3 or later
(LICENSE-FFmpeg-LGPL-3.0.txt, which adds to LICENSE-FFmpeg-GPL-3.0.txt; FFmpeg itself is LGPL 2.1 or later,
LICENSE-FFmpeg-LGPL-2.1.txt).
Source code: https://ffmpeg.org/releases/ffmpeg-6.1.1.tar.xz - build script: ffmpeg/cppbuild.sh in
https://github.com/bytedeco/javacpp-presets/tree/1.5.10 - https://ffmpeg.org/legal.html
Replace it: put your own ffmpeg(.exe) in config/concertstage/livevision/ (used first).
